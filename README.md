# uber-bookings-dashboard

A Power BI dashboard analyzing Uber ride bookings — tracking completed/lost bookings, booking value, distance, and ratings by vehicle type and location.

## Overview
This dashboard gives a quick operational view of Uber ride booking data, combining KPI summaries, time trends, and category/location breakdowns on a single interactive page.

## Features
- **KPI cards**: Completed Bookings, Lost Bookings, Booking Value, Total Distance, Avg Distance
- **Trend charts**: Completed Bookings and Booking Value by Month/Quarter
- **Category breakdown**: Booking Value by Vehicle Type
- **Location insights**: Top Pickup and Drop locations
- **Ratings**: Average Customer Rating and Average Driver Rating
- **Interactive filter**: Vehicle Type slicer

## Tools
- Power BI Desktop
- DAX for custom measures

## How to view
Download `uber dashboard project.pbix` and open it in [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free).
